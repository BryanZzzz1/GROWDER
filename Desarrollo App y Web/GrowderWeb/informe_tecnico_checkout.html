Auditoría Técnica de Arquitectura & Código

Informe Técnico: Flujo Transaccional de Checkout y Persistencia Supabase

Análisis forense de la implementación Web, diagnóstico de omisiones en el cliente móvil y especificación exacta para la replicación en Ionic/Android.

Proyecto SuMateCL / Growder Web & Mobile
Entorno Web Auditado Next.js 15 (App Router) + Supabase JS
Entorno Móvil Destino Ionic Framework + Angular + Capacitor
Estado de la Transaccionalidad Discrepancia Crítica en Móvil

1 Resumen Ejecutivo: Diagnóstico de Fallas en App Móvil

⚠️
Causa Raíz Identificada: La app móvil (checkout.page.ts) delega el flujo de compra exclusivamente a la invocación de una Edge Function / Pasarela de Pago sin antes realizar la persistencia transaccional directa en la base de datos de Supabase. A diferencia de la Web, omite el ciclo de vida de reserva de stock, inserción en la tabla pedidos con el JSONB items, y la posterior limpieza del carrito.

Durante la auditoría del repositorio se verificó que la versión Web resuelve el flujo de compra mediante un patrón de dos fases desacopladas:

1
Fase 1: Pre-reserva e Inserción de Pedido (Frontend Web)
En app/confirmacion-pago/page.tsx, antes de llamar al endpoint de Webpay o Mercado Pago, la aplicación realiza un INSERT con estado 'pendiente' en la tabla pedidos almacenando los datos de despacho, totales y el snapshot de los productos en formato JSONB. Paralelamente ejecuta un bloqueo/descuento temporal de stock por 120 segundos mediante /api/reserva/iniciar (RPC crear_reserva_stock).
2
Fase 2: Retorno y Cierre de Transacción (Webhook / Retorno Web)
Al retornar de Transbank en /api/webpay/commit o en /pago/exito, el backend actualiza el estado del pedido, llama a /api/reserva/completar (RPC completar_reserva) para consolidar el inventario, y el cliente ejecuta limpiarCarrito().
📱
¿Por qué falla el botón en la App Móvil? En el entorno móvil, al pulsar el botón de pagar, se genera una llamada HTTP hacia la Edge Function de pago esperando que esta sea la que inserte la orden en Supabase. Dado que la Edge Function solo retorna el token de Webpay/Mercado Pago, y la app no realiza el supabase.from('pedidos').insert(...) previo ni el webhook de callback consolida la orden huérfana, la compra ocurre a nivel financiero pero no existe registro alguno en las tablas pedidos ni historial_compras, y la pantalla del cliente no vacía el carrito.

useEffect(() => {
  let montado = true;

  async function verificarSesion() {
    try {
      const { data: { session } } = await supabase.auth.getSession();
      const user = session?.user;

      if (user || usuario) {
        if (!montado) return;
        setEstaAutenticado(true);
        const emailActivo = user?.email || usuario?.email || '';
        if (emailActivo) setEmail(emailActivo);

        const meta = user?.user_metadata || {};
        if (meta.nombre) setNombre(meta.nombre);
        if (meta.telefono) setTelefono(meta.telefono);

        const userId = user?.id || usuario?.id;
        if (userId) {
          const { data } = await supabase
            .from('usuario')
            .select('telefono')
            .eq('id', userId)
            .single();

          if (data?.telefono && !meta.telefono) {
            setTelefono(data.telefono);
          }
        }
      } else if (!authCargando) {
        if (!montado) return;
        setEstaAutenticado(false);
      }
    } catch (err) {
      console.error('Error al verificar sesión:', err);
      if (montado && !authCargando) {
        setEstaAutenticado(!!usuario);
      }
    }
  }

  verificarSesion();

  const {
    data: { subscription },
  } = supabase.auth.onAuthStateChange((_event, session) => {
    if (!montado) return;
    if (session?.user) {
      setEstaAutenticado(true);
      if (session.user.email) setEmail(session.user.email);
      const meta = session.user.user_metadata || {};
      if (meta.nombre) setNombre(meta.nombre);
      if (meta.telefono) setTelefono(meta.telefono);
    } else {
      setEstaAutenticado(false);
    }
  });

  return () => {
    montado = false;
    subscription.unsubscribe();
  };
}, [usuario, authCargando]);

const { data: rpcData, error: rpcError } = await supabase.rpc(
  'crear_reserva_stock',
  {
    p_codigo_reserva: codigoReserva,
    p_items: items,

    p_usuario_id: usuarioId || null,
    p_email: email || null,
  }

// Fallback directo en tabla si RPC no responde:
for (const item of items) {
  const idprod = item.idproducto || item.id;
  const { data: prod } = await supabase
    .from('producto')
    .select('cantidad')
    .eq('idproducto', idprod)
    .single();

  if (prod) {
    const nuevoStock = Math.max(0, prod.cantidad - item.cantidad);
    await supabase
      .from('producto')
      .update({ cantidad: nuevoStock })
      .eq('idproducto', idprod);
  }
}

3 Matriz de Brechas: Versión Web vs. Versión Móvil

Comparación pormenorizada de operaciones sobre Supabase, endpoints llamados y sincronización de estado:

Operación / Flujo Versión Web (Next.js) Versión Móvil Actual (Ionic) Estado Móvil Impacto Técnico
Validación de Sesión supabase.auth.getSession() + select en usuario para datos de contacto. Verificación parcial mediante servicio Auth; no precarga teléfono/nombre del perfil. Parcial Faltan campos obligatorios en el formulario si el usuario no los llena manualmente.
Apartado / Reserva de Stock Invoca RPC crear_reserva_stock y timer de 2 minutos. Omitido completamente. No consulta inventario previo. No Implementado Riesgo de sobreventa si dos usuarios compran la última unidad al mismo tiempo.
Persistencia del Pedido supabase.from('pedidos').insert({...}) con JSONB items y estado 'pendiente'. Omitido. Asume que la pasarela o Edge Function hace el insert. Crítico / Faltante No se genera el registro en pedidos. El pedido no existe para el panel de administración.
Estructura JSONB de Items Array de objetos con idproducto, nombre, precio, cantidad, imagen. Solo envía un payload plano de monto total a la Edge Function de pago. Faltante La pantalla de Mis Compras y el despacho no pueden reconstruir qué artículos compró el cliente.
Registro en Historial / Compras Lectura centralizada vía usuario_id / email_cliente sobre tabla pedidos con Realtime. Intenta consultar tabla inexistente o no encuentra registros por falta de insert previo. Bloqueado La vista de órdenes del cliente aparece vacía permanentemente.
Descuento Definitivo de Stock RPC completar_reserva o update directo en tabla producto al autorizar pago. Depende exclusivamente de webhooks de pasarela (que no están suscritos a la Edge Function móvil). Faltante El inventario no se descuenta tras la compra en móvil.
Vaciado del Carrito limpiarCarrito() en página de éxito + borrado de sessionStorage. No se dispara en el callback de retorno del In-App Browser / AppURLOpen. Faltante El usuario regresa a la app y los productos continúan en el carro, provocando recompras accidentales.

4 Propuesta de Integración para Android / Ionic (Angular)

A continuación se detalla la implementación lista para producción en el archivo src/app/pages/checkout/checkout.page.ts. Esta arquitectura replica con exactitud los estándares de la Web e incorpora los controladores nativos de Ionic (LoadingController, ToastController, AlertController).

src/app/pages/checkout/checkout.page.ts → Código de Integración Completo TypeScript / Ionic Angular 
import { Component, OnInit } from '@angular/core';
import { Router } from '@angular/router';
import { LoadingController, ToastController, AlertController } from '@ionic/angular';
import { createClient, SupabaseClient } from '@supabase/supabase-js';
import { environment } from 'src/environments/environment';
import { CartService, CartItem } from 'src/app/services/cart.service';

@Component({
  selector: 'app-checkout',
  templateUrl: './checkout.page.html',
  styleUrls: ['./checkout.page.scss'],
})
export class CheckoutPage implements OnInit {
  private supabase: SupabaseClient;

  // Datos del Cliente y Despacho
  nombreCliente: string = '';
  emailCliente: string = '';
  telefonoCliente: string = '';
  region: string = 'Región Metropolitana de Santiago';
  comuna: string = '';
  direccion: string = '';
  depto: string = '';
  instrucciones: string = '';

  metodoPago: 'webpay' | 'mercadopago' = 'webpay';
  costoEnvioFijo: number = 2650;
  itemsCarrito: CartItem[] = [];
  subtotal: number = 0;
  totalFinal: number = 0;

  usuarioId: string | null = null;
  procesando: boolean = false;

  constructor(
    private cartService: CartService,
    private router: Router,
    private loadingCtrl: LoadingController,
    private toastCtrl: ToastController,
    private alertCtrl: AlertController
  ) {
    this.supabase = createClient(environment.supabaseUrl, environment.supabaseKey);
  }

  async ngOnInit() {
    await this.cargarCarritoYTotales();
    await this.verificarSesionUsuario();
  }

  private async cargarCarritoYTotales() {
    this.itemsCarrito = await this.cartService.getItems();
    this.subtotal = this.cartService.getTotalPrice();
    this.totalFinal = this.subtotal + (this.itemsCarrito.length > 0 ? this.costoEnvioFijo : 0);

    if (this.itemsCarrito.length === 0) {
      this.mostrarToast('Tu carrito está vacío', 'warning');
      this.router.navigate(['/tabs/catalogo']);
    }
  }

  /**
   * 1. Valida la sesión activa en Supabase Auth y precarga datos
   */
  async verificarSesionUsuario() {
    try {
      const { data: { session } } = await this.supabase.auth.getSession();
      if (session?.user) {
        this.usuarioId = session.user.id;
        this.emailCliente = session.user.email || '';

        const meta = session.user.user_metadata || {};
        if (meta['nombre']) this.nombreCliente = meta['nombre'];
        if (meta['telefono']) this.telefonoCliente = meta['telefono'];

        // Consulta complementaria en tabla pública 'usuario'
        const { data: perfil } = await this.supabase
          .from('usuario')
          .select('telefono')
          .eq('id', this.usuarioId)
          .single();

        if (perfil?.telefono && !this.telefonoCliente) {
          this.telefonoCliente = perfil.telefono;
        }
      }
    } catch (err) {
      console.error('Error al recuperar sesión:', err);
    }
  }

  private generarCodigoPedido(): string {
    return `SM-${Math.floor(100000 + Math.random() * 900000)}`;
  }

  private validarFormulario(): boolean {
    if (!this.nombreCliente.trim()) {
      this.mostrarToast('Ingresa tu nombre y apellido', 'danger');
      return false;
    }
    if (!this.telefonoCliente.trim()) {
      this.mostrarToast('Ingresa tu teléfono de contacto', 'danger');
      return false;
    }
    if (!this.emailCliente.trim() || !this.emailCliente.includes('@')) {
      this.mostrarToast('Ingresa un correo electrónico válido', 'danger');
      return false;
    }
    if (!this.comuna.trim()) {
      this.mostrarToast('Ingresa tu comuna o ciudad', 'danger');
      return false;
    }
    if (!this.direccion.trim()) {
      this.mostrarToast('Ingresa tu calle y numeración', 'danger');
      return false;
    }
    return true;
  }

  /**
   * 2. Método principal de ejecución de Checkout
   */
  async ejecutarCheckout() {
    if (!this.validarFormulario()) return;

    const loading = await this.loadingCtrl.create({
      message: 'Registrando pedido y preparando pago...',
      spinner: 'crescent'
    });
    await loading.present();

    const codigoOrden = this.generarCodigoPedido();

    try {
      // A. Mapeo de items para compatibilidad JSONB exacta con la Web
      const itemsPayload = this.itemsCarrito.map(item => ({
        idproducto: item.idproducto || item.id,
        nombre: item.nombre,
        precio: item.precio,
        cantidad: item.cantidad,
        imagen: item.imagen || item.foto || ''
      }));

      // B. INSERT TRANSACCIONAL EN TABLA 'pedidos'
      const { error: dbError } = await this.supabase
        .from('pedidos')
        .insert({
          codigo_pedido: codigoOrden,
          usuario_id: this.usuarioId || null,
          email_cliente: this.emailCliente.trim(),
          nombre_cliente: this.nombreCliente.trim(),
          telefono_cliente: this.telefonoCliente.trim(),
          region: this.region,
          comuna: this.comuna.trim(),
          direccion: this.direccion.trim(),
          depto: this.depto ? this.depto.trim() : null,
          instrucciones: this.instrucciones ? this.instrucciones.trim() : null,
          metodo_pago: this.metodoPago,
          estado: 'pendiente',
          subtotal: this.subtotal,
          costo_envio: this.costoEnvioFijo,
          total: this.totalFinal,
          items: itemsPayload
        });

      if (dbError) {
        throw new Error(`Error en base de datos: ${dbError.message}`);
      }

      // C. Invocación de Reserva / Descuento de Stock
      try {
        await this.supabase.rpc('crear_reserva_stock', {
          p_codigo_reserva: codigoOrden,
          p_items: itemsPayload,
          p_duracion_segundos: 120,
          p_usuario_id: this.usuarioId,
          p_email: this.emailCliente
        });
      } catch (stockErr) {
        console.warn('RPC de reserva no ejecutada o en fallback:', stockErr);
      }

      // D. Invocar la Edge Function o Pasarela correspondiente
      await loading.dismiss();
      await this.iniciarPasarelaPago(codigoOrden, this.totalFinal);

    } catch (err: any) {
      await loading.dismiss();
      console.error('Error durante el proceso de compra:', err);
      const alert = await this.alertCtrl.create({
        header: 'Error en la Orden',
        message: err.message || 'No se pudo procesar tu pedido. Inténtalo nuevamente.',
        buttons: ['Aceptar']
      });
      await alert.present();
    }
  }

  /**
   * 3. Abre la pasarela e implementa el listener de éxito/limpieza
   */
  private async iniciarPasarelaPago(codigoOrden: string, monto: number) {
    // Ejemplo de llamada a la Edge Function de Webpay / Mercado Pago
    const { data, error } = await this.supabase.functions.invoke('iniciar-pago', {
      body: {
        codigoOrden,
        monto,
        metodo: this.metodoPago
      }
    });

    if (error || !data?.url) {
      this.mostrarToast('Error al conectar con la pasarela de pagos', 'danger');
      return;
    }

    // Al confirmarse el pago exitoso (mediante Deep Link o retorno in-app):
    // 1. Descontar stock consolidado
    // 2. Limpiar carrito
    // 3. Redirigir a confirmación
    await this.finalizarCompraExitosa(codigoOrden);
  }

  public async finalizarCompraExitosa(codigoOrden: string) {
    // Vaciar el carrito en el servicio y en Storage local
    await this.cartService.limpiarCarrito();
    
    // Notificación y redirección
    this.mostrarToast('¡Pago completado con éxito!', 'success');
    this.router.navigate(['/pedido-exito'], {
      queryParams: { orden: codigoOrden, total: this.totalFinal }
    });
  }

  private async mostrarToast(mensaje: string, color: 'success' | 'warning' | 'danger') {
    const toast = await this.toastCtrl.create({
      message: mensaje,
      duration: 3000,
      color: color,
      position: 'bottom'
    });
    await toast.present();
  }
}
